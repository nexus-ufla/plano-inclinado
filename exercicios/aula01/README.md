# Exercícios - Aula 1

Resolva os exercícios desta pasta depois de estudar o notebook `aulas/aula01_introducao_programacao.ipynb`.

## Arquivos

- `exercicio01_energia.py`: variáveis, operações matemáticas e funções.
- `exercicio02_movimento.py`: listas, laços de repetição e atualização de posição.
- `exercicio03_grafico_queda_livre.py`: NumPy, Matplotlib e gráfico de queda livre.

## Como executar

No terminal, estando na raiz do repositório:

```bash
python exercicios/aula01/exercicio01_energia.py
python exercicios/aula01/exercicio02_movimento.py
python exercicios/aula01/exercicio03_grafico_queda_livre.py
```

Cada aluno deve copiar suas soluções para sua própria pasta dentro de `entregas/`, quando essa pasta for criada.
